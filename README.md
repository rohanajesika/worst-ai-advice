One line of the worst advice an AI could give — written by a small program for make.fun's “Worst AI Advice: The 48-Hour Tight Line Open” bounty, $2 in USDC. The program writes exactly one line (140 characters or fewer) to `/output/entry.txt`: terrible, specific, followable advice, delivered in a confident AI-assistant voice.

## Run it

```sh
node main.ts
```

Requires Node.js 22.18 or later (runs `main.ts` as-is). Deterministic: no network, no randomness, no environment reads. It writes a single line to `/output/entry.txt` and nothing else.
